# AI 会话小票：各家的样例

每个编程助手结束一次会话，Notchfax 就从刘海里打一张小票。各家的钩子机制和会话记录格式都不一样，所以 Notchfax 不替它们装。这里放的是几个已经在用的实现，可以直接装，也可以给别的助手照着改。

| 目录 | 助手 | 触发点 | 数据从哪来 |
|---|---|---|---|
| [`claude-code/`](claude-code/) | Claude Code | `SessionEnd` hook | 会话转录 `.jsonl`，按 Anthropic API 标价算 |
| [`pi/`](pi/) | Pi | 扩展的 `session_shutdown` 事件 | 内存里的会话记录，按 Pi 自带的模型价目表算 |
| [`opencode/`](opencode/) | OpenCode | 插件记下会话，后台进程等 TUI 退出 | OpenCode 的 SQLite 库，用它自己记的花费 |
| [`dsh/`](dsh/) | DeepSeek Harness 桌面版 | 会话归档、退出 App 时 agent 卸载 | 会话日志 `.jsonl.zstd`，按 DeepSeek 标价分时段算 |

每个目录里都写了怎么装、怎么关、怎么手动打一张（Claude Code 的写在脚本开头）。

## 共同的做法

给新的助手写的话，照这几条来：

- **钩子马上返回。** 钩子里只记下要结哪个会话，打印放到一个脱离出去的子进程里做，不拖慢会话结束。
- **出错就安静退出。** 错误写进 `~/Library/Logs/Notchfax/<助手>-receipt.log`，不往助手的界面上报。
- **用完整路径调用 Notchfax。** 钩子运行时 PATH 常常不全，用 `/Applications/Notchfax.app/Contents/MacOS/Notchfax print --quiet --name <名字>`，留一个 `NOTCHFAX_BIN` 环境变量可以改路径。
- **只给人手动开的交互式会话出票。** 脚本、CI、子代理、派生的子会话都不打。
- **续接的会话只算新增的部分。** 记账状态放在 `~/Library/Application Support/Notchfax/<助手>-receipts.json`，记下每个会话结到了哪里。多个进程可能同时结账，读改写要加文件锁。
- **只印查得到的数字。** 价目表里没有的模型照样列出 token，但不写金额，也不算进合计，然后注明「不在价目表上，未计入」。
- **能手动跑。** 不管会话结束没结束，都能打一张；加 `--dry-run` 只在终端里显示。会话进行中打的叫「对账单」或「样票」，不动记账状态。

## 小票的样子

排版标记见 `notchfax help`。几家统一成这个格式：

```text
# PI                                   ← 助手名
^ > 会话小票 No.01A1D347                ← 续接的写「会话小票 · 续」，手动的写「对账单」
---
项目	notchfax                       ← 工作目录名
开始	11-13 13:00                    ← MM-dd HH:mm，本地时间
结束	11-13 13:46                    ← 对账单写「截至」
用时	45 分
对话	12 问 · 86 次调用               ← 有就写
---
## Claude Opus 5.5	$5.87          ← 每个模型一节，按金额从高到低
> 输入 144	<$0.01
> 输出 20.4万	$4.08              ← token：一万以下写千分位，以上写「万」「亿」
> 缓存写 12.6万	$0.63
> 缓存读 578.2万	$1.16
---
# 合计	$5.87                      ← 金额两位小数，不到一分写 <$0.01
^ > 按官方 API 标价估算                 ← 说明价格从哪来
^ > 续接会话，只计本次新增               ← 有需要才写
===
^ > 谢谢惠顾 · 欢迎再来
```

`左<Tab>右` 是两栏，右栏靠右。一张纸最高约 1400 点，超了 `notchfax print` 会报错，所以名字要截短（项目 18 个字，模型 22 个字）。
